# Obsidian Vault 디렉토리 이름 변경 계획

## Context
`00-MOC`와 `01-Concepts` 디렉토리명이 의미가 직관적이지 않아 이모지 + 한글 조합으로 변경.
디렉토리명 변경 시 DataView 쿼리 경로도 함께 수정 필요.

## 변경 사항

| 기존 이름 | 새 이름 |
|-----------|---------|
| `00-MOC` | `🧭학습로드맵` |
| `01-Concepts` | `📚학습노트` |

## 수정 대상 파일

### 1. 디렉토리 이름 변경 (2건)
```bash
mv "00-MOC" "🧭학습로드맵"
mv "01-Concepts" "📚학습노트"
```

### 2. MOC 파일 내 DataView 쿼리 경로 수정 (4개 파일, 약 10곳)
`FROM "01-Concepts/..."` → `FROM "📚학습노트/..."`

- `🧭학습로드맵/Data-Layer-MOC.md` — 2곳
- `🧭학습로드맵/Hybrid-Search-MOC.md` — 2곳
- `🧭학습로드맵/LLM-RAG-MOC.md` — 2곳
- `🧭학습로드맵/Kotlin Spring 시니어 성장 커리큘럼 MOC.md` — 3곳

## 영향 없는 부분
- Obsidian 위키링크(`[[...]]`): 파일명 기반이므로 폴더명 변경에 영향 없음
- 개별 학습 노트 내용: 폴더 경로를 참조하지 않음
- Tags 디렉토리: 변경 없음

## 실행 순서
1. 디렉토리 이름 변경 (`mv`)
2. MOC 파일 내 DataView 쿼리 경로 일괄 수정

## 검증
- Obsidian에서 각 MOC 페이지를 열어 DataView 테이블이 정상 렌더링되는지 확인
- 사이드바에서 이모지 정렬 순서 확인
