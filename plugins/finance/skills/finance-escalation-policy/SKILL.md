# 재무·세무 에스컬레이션 정책

세무 리스크는 오판 비용이 비대칭적이다 — 놓친 가산세·추징·형사 리스크는 과잉 경고보다 훨씬 비싸다. 아래 정책에 해당하면 보고서 최상단에 **"⚠️ 반드시 세무사/회계사 상담"**을 강제 표시하고, 하네스 산출물만으로 신고·소명·납부 결정을 내리지 않도록 안내한다.

## When to Apply

- finance 에이전트(finance-analyst, tax-risk-advisor)가 보고서를 작성할 때 (매번 판정)
- finance 커맨드(/expense-review, /financial-review, /tax-risk-scan)의 최종 보고 단계
- 사용자가 세무 통지·기한·고액 쟁점을 언급할 때

## 판단 기준 축

**(1) 세무조사 가능성, (2) 금액 규모, (3) 신고기한 임박.** 하나라도 강하게 해당하면 강제.

## 트리거 표

| # | 트리거 | 수준 | 안내·행동 |
|---|--------|------|----------|
| 1 | 과세관청 접촉 — 세무조사 사전통지, 세무서 소명(해명자료) 요구, 과세예고통지, 수정신고 권고 수령 | **강제** | 분석은 제공하되 "과세관청 답변·자료 제출 전 세무사 상담"을 최상단에 표시. 소명서 답변을 직접 확정 설계하지 않음 |
| 2 | 조세범 처벌 결부 신호 — 허위(가공) 세금계산서, 자료상 거래 의심, 이중장부·매출 누락 은폐 등 부정행위 성격 쟁점 | **강제** | 일반적 구조 설명에 그치고 "즉시 세무사(필요 시 변호사) 상담" 강제. 사실관계 단정·대응 전략 상세화 자제 |
| 3 | 신고기한 임박·경과 — 법정 신고·납부 기한이 **7일 이내**이거나 이미 경과했는데 무신고/과소신고 상태 | **강제** | 기한과 기한후신고·수정신고 선택지를 우선 안내하고 "제출 전 세무사 확인" 표시 |
| 4 | 고액 쟁점 — 예상 추징세액·쟁점 금액 **1천만원 이상**, 또는 특수관계자 거래·국외 거래·사업 양수도가 결부 | **강제** | 신고·납부·자금 이동 전 세무사 검토 강제. 하네스 산출물만으로 실행 금지 안내 |
| 5 | 불복·경정 절차 — 이의신청·심판청구·경정청구를 진행 중이거나 진행하려는 단계 | **강제** | 불복 기한을 우선 안내하고 "대리인 선임 후 본안 대응" 표시 |
| 6 | 중액 쟁점 — 쟁점 금액 **100만원~1천만원**, 또는 반복 발생 구조(매기 신고에 영향) | 권고 | 리스크 분석 제공 + "다음 신고 전 세무사 검토 권장" 안내 |
| 7 | 유권해석 갈림 — 과세·비과세, 공제 가능 여부 해석이 갈리고 가산세 가능성이 중간 이상 | 권고 | 양 해석을 제시하고 국세청 유권해석(서면질의·사전답변) 확인 + 전문가 검토 권고 |
| 8 | 처리 방식 전환 — 프리랜서↔근로자 구분 변경, 간이↔일반 전환, 법인 전환 등 구조 변경 **직전** 단계 | 권고 | 전환 체크리스트 제공 + "실행 전 세무사 검토 권장" |

## 적용 규칙

- 강제 트리거는 보고서 **최상단**(제목 바로 아래)에 `⚠️ 반드시 세무사/회계사 상담`과 해당 사유를 표시
- 강제·권고가 동시 해당하면 **강제 우선**
- 트리거가 모호하면 **상향(보수적)** 적용 — 놓치는 비용이 과잉 경고 비용보다 크다
- 여러 에이전트가 같은 항목을 공통 지적하면 등급을 한 단계 상향
- 금액 산정이 불가능하지만 고액 가능성이 있으면 강제로 취급 (금액 불명 ≠ 저위험)

## 보고서 표기 형식

강제 트리거 해당 시 보고서 최상단에 아래 블록을 배치한다:

```markdown
> ⚠️ **반드시 세무사/회계사 상담**
> 해당 트리거: [#번호 — 사유 1줄]
> 본 보고서는 1차 리스크 진단이며, 이 산출물만으로 신고·소명·납부를 실행하지 마십시오.
```

권고 트리거는 보고서 말미 "전문가 상담 권고" 섹션에 사유와 함께 표기한다.

## Error Handling

| 상황 | 대응 |
|------|------|
| 금액·기한 정보 부족 | 추측 판정 금지 — 사용자에게 확인 후 판정. 확인 불가 시 보수적 상향 |
| 트리거 판정 근거인 기한·기준 불확실 | WebSearch로 당해연도 확인 (`korean-tax-foundations` 규약) |
| 에이전트 간 판정 상충 | 더 높은 수준(강제 > 권고) 채택 |

## Boundaries

**Will:**
- 3축 기반 강제/권고 트리거 판정
- 강제 경고 블록의 최상단 배치 강제
- 보수적 상향 및 공통 지적 상향 규칙 적용

**Will Not:**
- 확정적 세무 판단 (판정은 상담 필요 수준의 분류일 뿐)
- 세무사·회계사·변호사의 자문/불복 절차 대행
- 강제 트리거 사안에서 산출물만으로 실행하도록 유도
