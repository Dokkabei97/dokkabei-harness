# 한국 노동·지식재산 실무 가이드

## When to Apply
- 근로계약·취업규칙·해고·임금의 적법성을 점검할 때
- IP 권리 확보·보호·침해 대응 전략이 필요할 때
- 퇴사자 영업비밀 유출 등 노동·IP 교차 사안일 때

## 노동: 핵심 리스크

| 쟁점 | 법령 | 포인트 |
|------|------|--------|
| 근로계약 서면교부 | 근기법 §17 | 임금·소정근로시간·휴일·연차 서면 명시·교부 의무 |
| 해고 정당성 | §23 | 정당한 사유 必 — 경영상 해고는 §24 요건 |
| 해고 절차 | §27 | 서면통지(사유·시기), §26 30일 전 예고 또는 예고수당 |
| 부당해고 구제 | §28 | 노동위 구제신청(3개월 내) |
| 통상임금 | 판례 | 정기·일률·고정성 → 연장·야간·휴일수당 기준 |
| 포괄임금제 | 판례 | 근로시간 산정 곤란 시 제한적 유효 |
| 임금체불 | §109 | 형사처벌(반의사불벌) |
| 취업규칙 불이익변경 | §94 | 과반 노조/근로자 과반 동의 必 |

- **5인 미만 사업장**: 해고제한(§23①)·연장가산·연차 등 상당수 미적용 — 규모 먼저 확인
- **위장도급/프리랜서**: 사용종속성 있으면 근로자로 인정 → 4대보험·퇴직금 리스크

## 지식재산: 권리별 전략

| 권리 | 발생 | 존속 | 핵심 |
|------|------|------|------|
| 저작권 | 창작 즉시(무방식) | 사후 70년 | 업무상저작물 귀속(§9) 확인 |
| 상표권 | 등록주의 | 10년·갱신 | 출원 선점, 지정상품 분류 |
| 특허권 | 등록주의 | 출원 20년 | 신규성·진보성, 직무발명 |
| 디자인권 | 등록주의 | 출원 20년 | 신규성, 일부심사 |
| 영업비밀 | 관리 사실 | 비밀 유지 중 | 부정경쟁방지법, 3요건 |

## 직무발명·업무상저작물

- **직무발명(발명진흥법)**: 종업원 발명 → 사용자 통상실시권, 예약승계 시 정당 보상 의무
- **업무상저작물(저작권법 §9)**: 법인 기획 + 업무상 작성 + 법인 명의 공표 → 법인 귀속. 계약·취업규칙에 명확화 권장

## 영업비밀 3요건
1. **비공지성**: 공개되지 않음
2. **경제적 유용성**: 경제 가치
3. **비밀관리성**: 접근통제·표시·서약 등 관리 — 실무상 가장 자주 탈락

## 침해 대응 단계
```
증거 보전 → 경고장(내용증명) → 가처분(침해금지) → 본안(손배·형사)
※ 형사(특허침해·영업비밀누설)는 변호사·변리사 협업
```
