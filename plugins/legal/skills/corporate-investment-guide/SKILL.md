# 한국 기업·투자 법무 가이드

## When to Apply
- 투자 텀시트·계약 조건을 분석할 때
- 주주간계약·정관·지분 구조를 검토할 때
- 스톡옵션 부여 구조를 설계할 때

## 투자 핵심 조항 (창업자 관점)

| 조항 | 의미 | 창업자 주의점 |
|------|------|--------------|
| 청산우선권 | 청산/매각 시 우선 분배 | 1배·비참가가 창업자 유리, 다중·참가는 불리 |
| 희석방지 | 후속 저가 발행 시 보정 | full-ratchet은 가혹, broad-based weighted average 선호 |
| 동반매도청구(drag-along) | 다수 동의 매각 시 강제 동참 | 발동 요건·최소가격 보호 협상 |
| 동반매도참여(tag-along) | 대주주 매각 시 소수주주 참여권 | 창업자 보호 장치로 활용 |
| 우선매수권(ROFR) | 지분 양도 시 우선 매수 | 유동성 제약 — 범위 확인 |
| 거부권(veto) | 주요 의사결정 동의권 | 일상 경영 제약 최소화 |
| 옵션풀 | 스톡옵션 재원 | pre-money에 두면 창업자 희석↑ |

## 투자 수단 비교

| 수단 | 성격 | 특징 |
|------|------|------|
| 보통주 신주 | 지분 | 단순, 우선권 없음 |
| RCPS(상환전환우선주) | 우선주 | 한국 VC 표준, 상환+전환+우선권 |
| 전환사채(CB) | 부채→지분 | 전환가·이자, 후속 라운드 전환 |
| SAFE형/조건부지분 | 미래 지분 | 초기 간이 투자, 밸류 추후 확정 |

## 스톡옵션(주식매수선택권)

- 근거: 상법 §340조의2(정관·주총특별결의), 벤처기업법 특례(부여 한도·대상 완화)
- 핵심 설계: **행사가격**(시가 이상 원칙), **베스팅**(통상 4년·1년 클리프), **행사기간**, **퇴사 시 처리**
- 세무: 행사이익 과세 — 벤처기업 비과세 특례 요건 확인(전문가 검토)

## 거버넌스·통제권

- **의결권**: 보통결의(과반)·특별결의(2/3) 사안 구분
- **이사회**: 이사 지명권 배분이 실질 통제 좌우
- **정관 + SHA**: 정관(대외 효력)과 주주간계약(당사자 구속) 정합성 확인

## 희석 시뮬레이션 골격
```
라운드별: 투자금 / pre-money → post-money → 신주 비율
창업자 지분·의결권 추이 + 옵션풀 반영
→ 다운라운드/희석방지 발동 시나리오까지 점검
```
