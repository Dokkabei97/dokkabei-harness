# 한국 규제 컴플라이언스 가이드

## When to Apply
- 서비스의 개인정보 처리·전자상거래·광고 규제 준수를 점검할 때
- 약관·개인정보처리방침의 법정 필수기재를 검토할 때
- 코드/운영에서 규제 위반 흔적을 찾을 때

## 개인정보 라이프사이클 점검 (개인정보보호법)

| 단계 | 점검 항목 |
|------|----------|
| 수집·이용 | 동의 적법성(필수/선택 분리), 목적 명시, 최소수집, 민감·고유식별정보 별도 동의 |
| 제공·위탁 | 제3자 제공 동의/고지, 처리위탁 공개·위탁계약, 재위탁 |
| 국외이전 | 동의 또는 고지, 이전 국가·항목·목적 명시 |
| 보관·파기 | 보유기간 설정, 목적달성 시 파기, 분리보관 |
| 안전성 | 접근권한·접근통제, 암호화, 접속기록 보관·점검, 망분리(요건 시) |
| 정보주체 권리 | 열람·정정·삭제·처리정지, 자동화 결정 거부·설명요구(2024 시행) |

- **만 14세 미만**: 법정대리인 동의 必
- **유출 통지·신고**: 정보주체 통지 + 개인정보위/KISA 신고(요건·기한 확인)
- **개인정보처리방침**: 법정 기재사항 공개 의무

## 전자상거래법 (전자상거래 등에서의 소비자보호법)

- 사업자 정보 표시(상호·대표·사업자번호·연락처)
- **통신판매업 신고**(일정 규모 이상)
- **청약철회**: 원칙 7일 이내, 콘텐츠·예외 사유 구분
- 거짓·과장 표시·광고 금지, 표시광고법 병행

## 정보통신망법: 광고 규제

- 영리 목적 광고성 정보 전송 시 **사전 동의(옵트인)**
- 수신거부(옵트아웃) 수단·무료 제공
- **야간(21시~익일 08시)** 전송 시 별도 동의
- 제목·본문에 (광고) 표시

## 업종별 인허가 식별
- 통신판매업, 마이데이터(본인신용정보관리업), 전자금융, 헬스케어·의료, 위치정보사업 등
- 서비스 유형별 사전 신고·허가 요건 매핑

## 코드/운영 점검 팁 (Grep 활용)
```
수집 필드: email|phone|jumin|ssn|주민|생년월일|위치|location
동의 로직: consent|agree|optin|동의
로그 보존: access_log|audit|retention|보존기간
암호화: encrypt|hash|bcrypt|AES
```

## 위반 리스크 (정량화 시 참고)
- 과징금·과태료·형사처벌 병존 가능 — 항목별 제재 수준과 발생 가능성 표기
- 유권해석 갈리는 쟁점은 개인정보위 가이드라인 확인 후 "전문가 검토" 표시
