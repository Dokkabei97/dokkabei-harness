# Market Sizing Guide — 시장 규모 산정

## When to Apply
- 사업 기회의 시장 규모를 추정할 때
- 투자 유치 자료에 시장 데이터를 포함할 때
- 새로운 시장 진입 여부를 판단할 때

## TAM / SAM / SOM 프레임워크

```
┌─────────────────────────────────────┐
│            TAM                      │
│  ┌───────────────────────────┐      │
│  │         SAM               │      │
│  │  ┌─────────────────┐      │      │
│  │  │      SOM        │      │      │
│  │  └─────────────────┘      │      │
│  └───────────────────────────┘      │
└─────────────────────────────────────┘
```

| 구분 | 정의 | 관점 |
|------|------|------|
| **TAM** (Total Addressable Market) | 전체 시장 규모 | "만약 모든 잠재 고객을 확보한다면" |
| **SAM** (Serviceable Available Market) | 서비스 가능 시장 | "우리 제품이 도달 가능한 범위" |
| **SOM** (Serviceable Obtainable Market) | 실제 확보 가능 시장 | "현실적으로 1~3년 내 달성 가능" |

## 3가지 산정 접근법

### 1. Top-Down (하향식)
```
전체 산업 시장 규모 (리서치 보고서)
  → × 관련 세그먼트 비율
  → × 지역 비율
  → × 가격 조정 비율
  = TAM/SAM/SOM
```
**장점:** 빠르고 큰 그림 파악 가능
**단점:** 과대 추정 위험, 가정에 의존적
**적합:** 초기 탐색, 시장 매력도 평가

### 2. Bottom-Up (상향식)
```
타겟 고객 수 (구체적 세그먼트)
  × 제품 단가 (연간 또는 거래당)
  × 이용 빈도 (해당 시)
  = 시장 규모
```
**장점:** 구체적이고 현실적, 투자자 신뢰도 높음
**단점:** 시간 소요, 고객 수 추정이 핵심
**적합:** Seed 이후 투자 유치, 사업 계획서

### 3. Value Theory (가치 이론)
```
고객이 현재 지불하는 비용 (시간/돈)
  × 우리 솔루션이 절감하는 비율
  × 잠재 고객 수
  = 창출 가능 가치 (시장 기회)
```
**장점:** 고객 가치에 기반, 차별화된 관점
**단점:** 절감 비율 추정이 주관적
**적합:** 신규 카테고리 창출, 기존 시장 대체

## 산정 절차 (Step-by-Step)

### Step 1: 시장 정의
- 어떤 문제를 해결하는 시장인가?
- 기존 산업 분류에 해당하는가, 새로운 카테고리인가?
- 지역 범위는? (한국, 아시아, 글로벌)

### Step 2: 데이터 수집
| 소스 유형 | 국내 | 해외 |
|----------|------|------|
| 정부 통계 | 통계청, KOSIS, e-나라지표 | Census Bureau, Eurostat |
| 산업 리포트 | KISDI, KIET, 산업연구원 | Statista, IBISWorld, Gartner |
| 투자 데이터 | THE VC, 벤처스퀘어 | Crunchbase, PitchBook |
| 기업 공시 | DART, KIND | SEC Edgar, Annual Reports |
| 앱 데이터 | 와이즈앱 | App Annie, Sensor Tower |

### Step 3: 교차 검증
- Top-Down과 Bottom-Up 결과를 비교
- 차이가 3배 이상이면 가정 재검토
- 유사 기업의 실제 매출과 비교 (Sanity Check)

### Step 4: 성장률 추정
- 과거 3~5년 CAGR 산출
- 성장 드라이버와 저해 요인 식별
- 보수적/기본/낙관적 3가지 시나리오

## 투자자 관점 검증 기준

| 체크포인트 | 설명 |
|-----------|------|
| **산출 근거 명시** | 모든 숫자에 출처와 가정 표기 |
| **Bottom-Up 포함** | Top-Down만으로는 신뢰도 낮음 |
| **Sanity Check** | 유사 기업 매출과 비교 |
| **SOM 현실성** | SOM이 TAM의 1~5% 수준이 일반적 |
| **성장성** | 연 20%+ 성장 시장이 매력적 |
| **타이밍** | 왜 지금이 적기인지 설명 |

## 흔한 실수

| 실수 | 문제 | 해결 |
|------|------|------|
| TAM = Google 검색 결과 | 근거 없는 숫자 | Bottom-Up으로 교차 검증 |
| SAM = TAM의 10% | 임의 비율 적용 | 구체적 세그먼트 기반 산출 |
| "조 단위 시장" 강조 | TAM이 크다고 사업이 되는 것은 아님 | SOM과 도달 전략에 집중 |
| 단일 소스 의존 | 하나의 리포트만 인용 | 2개 이상 소스 교차 검증 |
