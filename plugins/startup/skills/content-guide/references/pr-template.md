# 보도자료(PR) 템플릿

기자가 그대로 기사로 옮길 수 있는 **역피라미드** 구조 — 가장 중요한 정보가 맨 위.
문체는 brand-voice.md와 무관하게 **합니다체·3인칭 객관 서술**이 기본이다(보도자료 관례).
근거 없는 수치·"업계 최초" 류 표현은 특히 위험 — 감지 시 legal `/compliance-check` 안내 1줄.

## 구조 (역피라미드)

```
1. 헤드라인       — 회사명 + 핵심 사실 1개 (30자 내외)
2. 서브헤드라인    — 헤드라인 보충 (선택, 1문장)
3. 리드 문단      — 5W1H: 누가·무엇을·언제·어디서·왜·어떻게. 이 문단만 실려도 기사가 됨
4. 본문 2~4문단   — 배경 → 상세 → 의미/전망 순으로 중요도 하강
5. 인용문 1~2개   — 대표(비전·의미) + 고객/파트너(효용) — 실명·직함 필수
6. 보일러플레이트  — 회사 소개 고정 문단 ("OO에 대하여")
7. 미디어 문의처   — 담당자·이메일 (개인 연락처는 [기재 필요]로 비워둠)
```

## 작성 규칙

| 규칙 | 내용 |
|------|------|
| 사실만 | 모든 수치·순위·최초 주장에 출처 병기. 근거 자산에 없으면 `[근거 필요]` |
| 3인칭 | "우리는" 금지 → "OO(회사명)는". 주관 형용사("혁신적인") 배제 |
| 인용문에만 감정 | 기대·포부·평가는 인용문 안에서만 허용 |
| 날짜 명시 | 발표일·출시일·수치 기준일을 본문에 명시 |
| 분량 | A4 1장(공백 포함 1,200~1,800자) 기본 |

## 인용문 규칙

- 형식: `[이름] [회사] [직함]은 "…"라고 말했다.`
- 대표 인용: 왜 만들었는가·무엇이 달라지는가 (비전)
- 고객/파트너 인용: 구체적 효용 — 인용 허락 여부를 `[인용 허락 확인 필요]`로 표기

## 배포 체크리스트

| # | 확인 |
|---|------|
| 1 | 헤드라인만 읽고 기사 제목을 뽑을 수 있는가 |
| 2 | 리드 문단에 5W1H가 모두 있는가 |
| 3 | 모든 수치에 출처·기준일이 있는가 (`[근거 필요]` 잔존 0건) |
| 4 | 인용문 실명·직함·허락 확인 완료 |
| 5 | "최초·최고·유일" 표현에 조사기관/근거 병기 또는 삭제 (리스크 시 legal 안내) |
| 6 | 보일러플레이트·문의처 포함 |
| 7 | 엠바고 여부·배포 희망일 명시 |

## 골격 예시

```markdown

검색 인프라 스타트업 OO(대표 ◇◇◇)는 2026년 7월 1일 검색 운영 자동화 도구
'△△'를 정식 출시했다고 밝혔다. △△는 재색인 판단과 승인 절차를 자동화해

[본문: 배경 — 문제의 규모와 기존 대안]

[고객 인용 — A사 엔지니어링 리드, 인용 허락 확인 필요]

### OO에 대하여

[담당자명] / [이메일 — 기재 필요]
```
