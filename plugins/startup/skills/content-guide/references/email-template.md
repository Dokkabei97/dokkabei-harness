# 이메일 템플릿

공통 원칙: **1 이메일 = 1 주제 = CTA 1개**. 열람은 제목줄이, 클릭은 본문 첫 3줄이 결정한다.
영리 목적 광고성 정보에 해당하면 §법정 표기를 반드시 포함한다.

## 유형별 목적

| 유형 | 목적 | 발송 트리거 |
|------|------|-------------|
| 뉴스레터 | 관계 유지·콘텐츠 배포 | 정기 (주/격주) |
| 온보딩 | 첫 가치 경험(Aha Moment) 유도 | 가입 후 시퀀스 (D0/D1/D3…) |
| 공지 | 기능 출시·정책 변경 전달 | 이벤트 발생 시 |
| 세일즈 | 전환·업그레이드 제안 | 세그먼트 조건 충족 시 |

## 구조

```
1. 제목줄        — 30자 내외, 이득/호기심 1개 (아래 규칙)
2. 프리헤더      — 제목줄 보충 1문장 (수신함 미리보기에 노출)
3. 인사·맥락 (1~2줄) — 왜 지금 이 메일을 받는지
4. 본문          — 주제 1개, 스캔 가능하게 (짧은 문단 + bullet)
   - 수치·사례는 brand-voice.md 근거 자산에서만
5. CTA 버튼/링크 — 1개만. 동사형 라벨 ("무료로 시작하기")
6. 서명          — 보내는 사람이 드러나게 (팀/개인 명의)
7. (광고성일 때) 법정 표기 — §법정 표기
```

## 제목줄 규칙

| 규칙 | 예 |
|------|-----|
| 구체적 이득 | "재색인 당번을 없애는 설정 3줄" |
| 수신자 관련성 | "○○님 팀의 지난주 검색 지표 요약" |
| 과장·전부대문자·과다 이모지 금지 | ~~"충격!! 100% 무료!!"~~ |
| 본문과 불일치 금지 | 제목의 약속을 본문 첫 3줄에서 이행 |

A/B용으로 제목줄 후보 2~3개를 함께 산출한다.

## 법정 표기 (광고성 정보일 때 — 정보통신망법)

영리 목적 광고성 정보 전송 시 아래를 갖춘다. **수신동의·야간전송 등 적법성 판정은
legal 플러그인 `/compliance-check`의 몫** — 여기서는 초안에 자리만 잡아둔다.

| 항목 | 표기 |
|------|------|
| 제목 | 제목줄 앞에 `(광고)` 표기 |
| 전송자 | 본문에 회사명·연락처 명시 |
| 수신거부 | 무료 수신거부 방법 안내 (한글 안내 + 링크/회신 수단) |

온보딩·거래 관련 안내 등 비광고성 메일은 해당 없음 — 애매하면 legal 안내 1줄을 남긴다.

## 골격 예시 (뉴스레터)

```markdown
제목줄: 재색인 당번을 없애는 설정 3줄
프리헤더: 파일럿 3개 팀의 계측 결과와 함께 정리했습니다.

안녕하세요, OO 팀의 ◇◇입니다.
지난달 베타에서 가장 많이 받은 질문을 글로 정리했습니다.

**병목은 실행이 아니라 판단이었습니다**
파일럿 3개 팀 계측 결과, 재색인 실행은 주 1시간이 안 됐고
나머지는 판단·승인·관찰이 차지했습니다. (내부 계측, 2026-05)

- 임계치 기반 자동 제안
- Slack 원클릭 승인
- 이상 시에만 알림

[전체 글 읽기]  ← CTA 1개

◇◇ 드림 / OO 팀

---
(광고) OO | 서울시 … | 02-000-0000
수신거부: [링크] (무료)
```
