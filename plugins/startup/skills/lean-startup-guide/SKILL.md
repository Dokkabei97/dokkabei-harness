# Lean Startup Guide — 린 스타트업 핵심 방법론

## When to Apply
- 새로운 사업 아이디어를 검증할 때
- MVP를 정의하고 스코프를 결정할 때
- 실험 결과를 바탕으로 피벗/유지를 결정할 때
- Customer Development 프로세스를 따를 때

## Core Framework: Build-Measure-Learn

```
         ┌─────────┐
    ┌───▶│  LEARN  │───┐
    │    └─────────┘   │
    │    가설 검증/반증   │ 가설 수립
    │                  │ (Riskiest Assumption)
┌───┴───┐          ┌───▼───┐
│MEASURE│◀─────────│ BUILD │
└───────┘          └───────┘
 핵심 지표 측정      최소한의 실험/MVP
```

**핵심 원칙:**
1. 만들기 전에 가장 위험한 가설부터 검증
2. 완벽한 제품이 아닌 학습을 위한 최소한의 것을 만듦
3. Vanity Metrics(허영 지표)가 아닌 Actionable Metrics(행동 지표) 측정
4. 검증된 학습(Validated Learning)만 진짜 진전

## Customer Development 4단계

| 단계 | 목표 | 핵심 질문 | 성공 기준 |
|------|------|----------|----------|
| **Customer Discovery** | 문제 존재 확인 | 이 문제가 실재하는가? | 인터뷰 대상의 40%+ 공감 |
| **Customer Validation** | 솔루션 수요 확인 | 사람들이 돈을 낼 것인가? | 유료 전환 또는 LOI 확보 |
| **Customer Creation** | 수요 창출 | 어떻게 고객에게 도달하는가? | 반복 가능한 채널 확보 |
| **Company Building** | 조직화/확장 | 어떻게 규모를 키우는가? | 부서별 KPI 달성 |

**Customer Discovery 인터뷰 원칙 (The Mom Test):**
- 아이디어가 아닌 고객의 삶에 대해 질문
- 미래 행동이 아닌 과거 행동에 대해 질문
- "좋다/나쁘다" 의견이 아닌 구체적 사실을 수집

## MVP 유형 선택 가이드

| MVP 유형 | 검증 대상 | 비용 | 기간 | 적합한 단계 |
|---------|----------|------|------|-----------|
| **Landing Page** | 가치 제안, 수요 | 낮음 | 1~3일 | Discovery |
| **Video/Demo** | 솔루션 관심도 | 낮음 | 1~5일 | Discovery |
| **Concierge** | 문제-솔루션 적합성 | 중간 | 1~4주 | Validation |
| **Wizard of Oz** | 솔루션 작동 가능성 | 중간 | 2~4주 | Validation |
| **Piecemeal** | 운영 가능성 | 중간 | 1~2주 | Validation |
| **Single Feature** | 핵심 가치 검증 | 높음 | 4~8주 | Validation |

**선택 기준:** 가장 적은 비용으로 가장 위험한 가설을 검증할 수 있는 유형

## Pivot 판단 프레임워크

**피벗 신호:**
- 핵심 지표가 3회 연속 실험에서 기준 미달
- 고객이 다른 기능/용도로 제품을 사용
- CAC가 LTV를 초과하며 개선 추세 없음
- 팀의 학습 속도가 현저히 둔화

**10가지 피벗 유형:**

| 피벗 유형 | 변경 내용 | 예시 |
|---------|---------|------|
| Zoom-in | 기능 → 제품 | Flickr(게임 내 사진) → 사진 서비스 |
| Zoom-out | 제품 → 기능 | 단독 앱 → 플랫폼의 한 기능 |
| Customer Segment | 다른 고객 | Slack(게임 팀 도구) → 모든 팀 |
| Customer Need | 다른 문제 | 고객은 같지만 다른 니즈 해결 |
| Platform | 앱 ↔ 플랫폼 | 단일 앱 → 에코시스템 |
| Architecture | B2C ↔ B2B | 개인 → 기업 또는 반대 |
| Value Capture | 수익 모델 변경 | 구독 → 거래 수수료 |
| Growth Engine | 성장 엔진 변경 | 바이럴 → 유료 광고 |
| Channel | 유통 채널 변경 | 직접 → 파트너/리셀러 |
| Technology | 기술 스택 변경 | 같은 솔루션, 다른 기술 |

## Key Metrics by Stage

| 단계 | 핵심 지표 | 목표 |
|------|----------|------|
| Problem-Solution Fit | 인터뷰 공감률, 문제 빈도 | 40%+ 공감 |
| MVP | 가입 전환율, 활성화율 | 업종별 상이 |
| Product-Market Fit | 리텐션(D7/D30), Sean Ellis 테스트 | 40%+ "매우 실망" |
| Scale | LTV/CAC, Payback Period, NPS | LTV/CAC > 3 |
