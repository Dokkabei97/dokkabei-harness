# 한국 계약법 실무 가이드

## When to Apply
- 계약서 조항의 리스크를 평가할 때
- 유형별 계약 초안을 작성하거나 누락 조항을 점검할 때
- 협상 우선순위와 수정 문구를 설계할 때

## 독소조항 체크리스트 (을 입장 기준)

| 영역 | 독소 신호 | 대응 |
|------|----------|------|
| 책임 | 무제한 손해배상, 간접손해 포함, 일방 면책 | 책임 한도(LoL) 설정, 간접·특별손해 배제 |
| 해지 | 상대방만 임의해지, 즉시해지, 무보상 | 상호 해지권, 통지기간, 정산 규정 |
| 금전 | 과도한 지체상금률, 위약벌, 일방 상계 | 지체상금 상한, 위약금/위약벌 명확화 |
| 지재권 | 모든 결과물·부수 IP 양도, 무상 광범위 라이선스 | 범위 한정, 기존 IP 제외, 출처표시 |
| 경업 | 장기·광범위 경업금지, 무보상 | 기간·지역·직무 합리적 제한 |
| 분쟁 | 상대방 본사 전속관할, 일방 유리 중재 | 합의관할, 중립지 중재 |

## 핵심 법리

- **약관규제법**: 약관(미리 작성된 정형 조항)은 불공정 시 무효. 개별약정은 약관 통제 밖 → "약관 vs 개별약정" 구분이 중요
- **위약금 추정(민법 §398)**: 위약금은 손해배상액 예정으로 추정. **과도하면 법원이 감액 가능**. 위약벌은 별도(감액 어려움) → 명시 필요
- **하자담보책임(민법 §580 등)**: 매매·도급의 하자담보. 면책특약 가능 범위 확인
- **불가항력**: 천재지변·법령변경 등 면책. 코로나 이후 조항 정교화 추세

## 유형별 필수 조항

| 유형 | 빠지면 위험한 조항 |
|------|------------------|
| NDA | 비밀정보 정의·범위, 존속기간, 반환·파기, 예외(공지·독자개발) |
| 용역/도급 | 검수 기준, 대금 지급조건, 하자보수, 지체상금, IP 귀속 |
| 라이선스 | 사용 범위(지역·기간·매체), 재라이선스, 보증·면책, 종료 후 처리 |
| 투자 | 진술보증, 선행조건, 우선권, 희석방지, 동반매도(별도 가이드) |

## Redline 작성 패턴

```
[조항] 제○조 (해지)
현재: "갑은 언제든 서면통지로 본 계약을 해지할 수 있다."
리스크: 을의 투자 회수 불가, 일방적 (High)
수정: "양 당사자는 30일 전 서면통지로 해지할 수 있으며,
       기수행 부분에 대한 대가를 정산한다."
근거: 형평성·민법상 신의칙, 상호주의
```

## 협상 우선순위 프레이밍
- **반드시 관철**: 강행규정 위반·비가역 손실 조항
- **협상 카드**: 양보 시 다른 조항 확보용
- **양보 가능**: 실익 적고 상대가 중시하는 조항
