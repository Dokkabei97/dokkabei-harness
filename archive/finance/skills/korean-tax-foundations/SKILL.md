# 한국 세무 기초 — 공통 토대

## ⚠ 최우선 규약: 세율·기준금액 하드코딩 금지

**이 스킬과 이를 참조하는 모든 에이전트·커맨드는 구체 세율·한도·기준금액·가산세율을 기억에서 인용하지 않는다.** 한국 세법은 매년 세법개정으로 수치가 바뀐다.

1. 판정에 세율·기준금액·한도·기한 날짜가 개입하면 **반드시 WebSearch로 당해연도 기준을 확인**한다
2. 1차 출처 우선: 국세청(nts.go.kr), 국가법령정보센터(law.go.kr), 홈택스 공지
3. 확인한 수치는 **출처와 확인 연도를 병기**한다 — 예) "(2026년 기준, 국세청 확인)"
4. 확인에 실패하면 수치를 비워 두고 "당해연도 기준 확인 필요"로 표기한다 — 추정치 기입 금지
5. 이 문서의 신고 주기·구조 서술도 개정될 수 있다 — 기한이 임박한 실무 판단에서는 재확인한다

## When to Apply

- 세무 관련 에이전트/커맨드가 공유하는 기본 구조가 필요할 때
- 경비·증빙의 세무 처리 방향을 판단할 때
- 신고 주기·가산세 리스크를 스크리닝할 때

## 세목 구조 (운영 단계 핵심 세목)

| 세목 | 납세 주체 | 과세 대상 | 실무 관점 |
|------|----------|----------|----------|
| 부가가치세 | 법인·개인사업자 (일반/간이 구분) | 재화·용역의 공급 | 매출·매입 세금계산서 정합성이 핵심 |
| 원천세(원천징수) | 소득 지급자 | 근로·사업·기타·퇴직소득 등 지급액 | 지급 시 징수·신고 + 지급명세서 제출 이중 의무 |
| 법인세 | 법인 | 사업연도 소득 | 손금 인정 여부(증빙·업무관련성)가 핵심 |
| 종합소득세 | 개인사업자 | 연간 종합소득 | 법인세의 개인 버전 — 장부·증빙 기반 신고 |
| 지방세(지방소득세 등) | 법인·개인 | 국세에 부가 | 국세 신고와 연동 — 별도 신고 누락 주의 |

- **간이과세 vs 일반과세**: 기준금액(하드코딩 금지 — 당해연도 확인)에 따라 구분되며 세금계산서 발급·공제 구조가 다르다
- 4대보험은 세금이 아니지만 인건비 처리·원천세와 실무상 연동된다 — 쟁점 시 별도 확인

## 신고 주기 축

구조만 서술한다. **구체 기한 날짜는 당해연도 국세청 신고 일정으로 확인.**

| 세목 | 주기 구조 | 비고 |
|------|----------|------|
| 부가가치세 | 과세기간(반기) + 예정/확정 신고 구조. 법인/개인, 일반/간이에 따라 신고 횟수 상이 | 조기환급 등 예외 절차 존재 |
| 원천세 | 원칙 매월 신고·납부, 요건 충족 시 반기 납부 특례 | 지급명세서 제출 기한은 소득 유형별로 별도 |
| 법인세 | 사업연도 종료 후 법정 기한 내 신고 + 중간예납 구조 | 성실신고확인 대상 여부에 따라 상이 |
| 종합소득세 | 연 1회 확정신고 + 중간예납 구조 | 성실신고확인 대상은 기한 상이 |
| 지방소득세 | 국세 신고와 연동 | 별도 신고 누락이 흔한 리스크 |

## 가산세 리스크 축

가산세 판단의 **유형 축**만 제공한다. 각 가산세율·감면율은 하드코딩 금지 — 당해연도 확인.

| 축 | 리스크 신호 | 완화 수단 (구조) |
|----|------------|-----------------|
| 무신고 | 신고 기한 경과 + 미신고 | 기한후신고 (빠를수록 감면 구조) |
| 과소신고 | 매출 누락·과다 공제 발견 | 수정신고 (빠를수록 감면 구조) |
| 납부지연 | 납부 기한 경과 (일할 가산 구조) | 조기 납부 |
| 증빙불비 | 적격증빙 미수취 지출 | 증빙 보완·거래사실 입증 |
| 지급명세서 미제출 | 인건비 지급 후 명세서 누락 | 기한 내/지연 제출 구분 |
| 세금계산서 관련 | 미발급·지연발급·허위 기재 | 허위(가공) 건은 조세범 처벌 결부 — 즉시 에스컬레이션 |

- 부정행위(이중장부·허위증빙 등)가 개입하면 가산세가 가중되고 부과제척기간이 길어지는 구조 — 해당 신호는 `finance-escalation-policy` 강제 트리거

## 적격증빙 체계

| 구분 | 종류 | 실무 포인트 |
|------|------|------------|
| 적격증빙 | 세금계산서, 계산서, 신용카드매출전표, 현금영수증(지출증빙용) | 공제·손금의 기본 전제 |
| 비적격증빙 | 간이영수증, 거래명세서 단독, 입금증 | 일정 금액 초과 시 증빙불비 리스크 (기준금액은 당해연도 확인) |
| 보완 자료 | 계약서, 송금 내역, 업무 관련성 소명 자료 | 증빙 공백 시 거래 실재성 입증용 |

- 접대비(기업업무추진비)·경조사비 등은 별도 증빙·한도 규정 존재 — 한도 수치는 당해연도 확인
- 증빙 보존 의무 기간 존재 — 기간 수치는 당해연도 확인

## 면책 원칙 (모든 산출물에 적용)

1. 모든 보고서는 **1차 리스크 스크리닝**이며, **세무사·회계사의 자문을 대체하지 않는다**
2. 확정적 단정("가산세 없다", "전액 공제된다", "적법하다") 금지 — 가능성·신호 수준으로 서술
3. 불확실한 기준·해석은 "세무사 확인 필요"로 명시
4. 탈루 행위(매출 누락 은폐, 가공경비, 허위 세금계산서)를 돕지 않는다

## 에스컬레이션 기준 (세무사/회계사 상담 필수 신호)

다음에 해당하면 산출물 최상단에 **"⚠️ 반드시 세무사/회계사 상담"**을 표시:
- 세무조사 사전통지·소명 요구·과세예고통지 등 과세관청 접촉
- 고액 쟁점 또는 조세범 처벌 결부 가능성(허위 세금계산서 등)
- 신고·납부 기한 임박 또는 경과 상태

> 상세 트리거와 강제/권고 구분은 `finance-escalation-policy` 스킬을 따른다.
